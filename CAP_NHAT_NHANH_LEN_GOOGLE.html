Toàn bộ 4 tính năng mới (Sửa Dashboard, Danh mục đầy đủ, Ô gợi ý Model, Camera Scanner) đã được đóng gói sẵn sàng trong file gas/Index.html!
Bạn chỉ cần làm 3 bước trong 15 giây:
1
Chạy file tự động copy code:
Tại thư mục máy tính, nhấp đúp file 3_TU_DONG_COPY_CODE.bat. Toàn bộ code mới sẽ tự động nạp sẵn vào bộ nhớ chuột của bạn!
2
Mở trang Google Apps Script:
Bấm nút xanh bên dưới để mở trang soạn thảo code. Ở cột bên trái, bấm chọn vào file Index.html.
3
Dán đè và Lưu lại:
Nhấn Ctrl + A (để chọn hết code cũ) → Nhấn Ctrl + V (để dán code mới) → Bấm biểu tượng Lưu (hoặc nhấn Ctrl + S).
